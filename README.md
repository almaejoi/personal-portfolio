# Almejoy C. Ancero | Personal Portfolio

A personal portfolio website showcasing my background, skills, academic projects, certificates, and contact information as a 4th-year Bachelor of Science in Computer Science student.

## Live Website

[Visit My Portfolio](https://almejoyancero.vercel.app/)

## About the Project

This personal portfolio website was developed to introduce myself, present my skills and academic projects, showcase my certificates, and provide my contact information.

The website features a responsive layout and interactive elements to provide a user-friendly browsing experience across desktop and mobile devices.

## Features

- **Home** – Introduction and personal information.
- **About Me** – Educational background and personal interests.
- **Projects** – Showcase of academic projects, including the Debt Tracker System.
- **Skills** – Presentation of design skills, tools, and technical knowledge.
- **Certificates** – Display of certificates with preview functionality.
- **Contact** – Contact and social media information.
- **Responsive Design** – Adaptable layout for desktop and mobile devices.
- **Dark Mode** – Theme switching functionality.
- **Interactive Navigation** – Navigation menu with active section highlighting.

## Technologies Used

| Technology | Purpose |

| HTML5 | Website structure and content |
